# Рилсы для этно-магазина (на казахском), полностью бесплатно

Готовые видео лежат в `out/`. Каждый рилс есть в двух вариантах:

| Файл | Что внутри |
|---|---|
| `out/<id>.mp4` | музыка + анимированный текст (основной вариант) |
| `out/<id>_dauys.mp4` | то же самое + казахская озвучка (синтез речи espeak-ng) |
| `out/<id>_cover.png` | обложка для Reels |

Формат: 1080×1920, 30 кадров/с, H.264 + AAC, громкость −14 LUFS. Это готовые файлы для Instagram Reels, TikTok и YouTube Shorts.

## Рилс из ваших фото товаров

Для живых фото есть готовая сцена `photo`: снимок в золотой рамке с орнаментом, плавное приближение и подпись.

1. Положите фото в папку `photos/`, например `photos/bilezik.jpg`. Лучше всего вертикальные снимки при дневном свете на однотонном фоне.
2. Скопируйте `reels/_foto-ulgi.json` в новый файл, например `reels/07-zhana-tauarlar.json`, и укажите свои фото в полях `src`.
3. Запустите `python3 build.py 07-zhana-tauarlar`.

Файлы, имя которых начинается с `_`, — это шаблоны: команда `python3 build.py` без аргументов их не собирает.

## Как изменить под свой магазин

1. `config.json`: название магазина (`brand.name`), слоган, `@аккаунт`, адрес, телефон. Пустые поля просто не показываются.
2. `reels/*.json`: тексты сцен (`text`, `title`, `kicker`) и текст озвучки (`voice`). Слова в `*звёздочках*` выделяются золотом. Иконки: `koshkar`, `shanyrak`, `saukele`, `dombra`, `kese`, `bilezik`, `gift`, `yurt`, `shapan`. Типы сцен: `hook`, `item`, `fact`, `photo`, `cta`.
3. Пересобрать: `python3 build.py` (все рилсы) или `python3 build.py 02-syilyk` (один).

Нужны: Python 3 с `numpy` и `scipy`, Node.js с Playwright (Chromium), `ffmpeg`, `espeak-ng`. Сборка трёх рилсов на 4 ядрах CPU занимает несколько минут, видеокарта не нужна.

## Из чего это сделано (всё бесплатно и без лимитов)

| Задача | Инструмент | Лицензия |
|---|---|---|
| Сценарии и тексты на казахском | Claude | — |
| Графика и анимация (орнаменты қошқар мүйіз, шаңырақ, иконки) | свой код: SVG + Chromium/Playwright, кадр за кадром | код в этой папке |
| Музыка (домбра, қағыс, барабан) | `render/music.py`, синтез струн Karplus-Strong | создана с нуля, без авторских прав |
| Озвучка | espeak-ng, казахский голос `kk` | GPL (сам звук можно использовать свободно) |
| Монтаж, сведение, ducking музыки под голос | ffmpeg | LGPL/GPL |
| Шрифты | Montserrat, Cormorant Garamond | SIL OFL |

Озвучка espeak-ng звучит роботизированно. Лучший бесплатный вариант — записать голос самому в CapCut, текст для озвучки есть в таблицах выше. Ещё можно поставить нейросетевой казахский голос Piper (`kk_KZ-issai-high`), если есть доступ к Hugging Face. В этом облачном окружении Hugging Face заблокирован.

## Исследование: бесплатные open-source модели

**Главное:** бесплатных облачных сервисов генерации видео *без лимитов* не существует. У всех бесплатных тарифов есть квоты. Модели с открытыми весами бесплатны и безлимитны, но работают только на видеокарте (GPU). Если своего компьютера нет, можно взять бесплатные GPU-часы в Kaggle или Colab, но и там действует недельная квота.

### Видео (open weights)
| Модель | Лицензия | Видеопамять | Комментарий |
|---|---|---|---|
| Wan 2.2 TI2V-5B (Alibaba) | Apache 2.0 | ~8 ГБ с offload | лучший выбор для бесплатного T4 (16 ГБ), 720p |
| Wan 2.2 A14B (T2V/I2V) | Apache 2.0 | 16–24 ГБ | качественнее, на бесплатном GPU на пределе |
| Wan 2.1 1.3B | Apache 2.0 | ~8 ГБ | 480p, быстрый и лёгкий |
| LTX-2 (Lightricks) | бесплатно для компаний с выручкой < $10 млн | высокие | видео сразу со звуком |
| HunyuanVideo 1.5 (Tencent) | Tencent community license | ~14 ГБ с offload | высокое качество |
| FramePack | Apache 2.0 | от 6 ГБ | оживление картинки (image-to-video) |
| Mochi 1, SkyReels, CogVideoX | разные | высокие | альтернативы |

Wan 2.5/2.6 доступны только через платный API, открытых весов нет.

### Картинки (open weights)
FLUX.1 [schnell] (Apache 2.0), Qwen-Image (Apache 2.0), HiDream-I1 (MIT), SDXL / SD 3.5 (бесплатно для выручки < $1 млн). Все требуют GPU.

### Где запустить без своего компьютера
- **Kaggle Notebooks**: около 30 GPU-часов в неделю, сессия до 12 часов. Для GPU нужно подтвердить номер телефона.
- **Google Colab (free)**: обычно T4, квота не публикуется, сессия до 12 часов.
- **Hugging Face ZeroGPU Spaces**: короткие демо с маленькой дневной квотой.
- В этом облачном окружении Claude видеокарты нет, а Hugging Face заблокирован. Поэтому видео собраны из анимированной векторной графики, а не нейросетью.

### Коннекторы в этой сессии
- Creative Claw: платный, на счёте 23 кредита. Одна картинка стоит ~16, одно видео ~48. Без пополнения им пользоваться нельзя.
- Для этой папки платные коннекторы не нужны.
